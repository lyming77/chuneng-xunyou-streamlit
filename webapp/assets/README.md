# 报告图表字体

`report-chart-font.ttf`为Google Fonts官方Noto Sans SC的图表用字子集，已改名为Storage Report Sans，许可见`OFL.txt`。字体仅覆盖`webapp/report_charts.py`中的固定标签和数值，不用于用户项目名称或Word正文。新增图表标签时须检查字形覆盖，必要时重新生成子集。

原始字体项目：https://github.com/notofonts/noto-cjk

子集来源：https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400 （按图表标签请求text子集）。保留字体内部版权与许可记录；Word正文继续采用固定报告模板中的字体设置。
